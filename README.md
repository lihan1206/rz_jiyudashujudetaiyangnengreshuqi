# 基于大数据的太阳能热水器健康度评估与故障诊断平台

## 🛠 技术栈
- Frontend: React 18 + TypeScript + Vite + Ant Design + ECharts + Zod
- Backend: FastAPI + SQLAlchemy + Pydantic
- Database: MySQL 8.0

## 🚀 启动指南 (How to Run)
1. 确保 Docker Desktop 已启动。
2. 在根目录执行：`docker compose up --build`
3. 等待容器启动完成后访问前端页面。

## 🔗 服务地址 (Services)
- Frontend: http://localhost:3207
- Backend Swagger: http://localhost:8207/docs
- Database: localhost:3307 (user: root / pass: root)
